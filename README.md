# Andrea Gentilini

MSc student in Mathematics in Data Science at TUM.

  [Paper](https://arxiv.org/abs/2611.26722) · [Code](https://github.com/tum-ai/toumaii-gen) · [Datasets](https://huggingface.co/collections/tum-ai/toumaii-generated-datasets)
- **zip2zip++** (*Preprint, 2026*) — adaptive tokenization for language models.<br>
  [Paper](https://arxiv.org/abs/2610.13605) · [Code](https://github.com/epfl-dlab/zip2zip-plus-plus) · [Models](https://huggingface.co/collections/epfl-dlab/zip2zip)
