# Andrea Gentilini

MSc student in Mathematics in Data Science at TUM.

A few projects:

- [zip2zip++](https://github.com/epfl-dlab/zip2zip-plus-plus) — adaptive tokenization for language models.
- [Explainable Italy](https://github.com/andrea-gentilini/explainable-italy) — official data on Italy, with European comparisons and transparent sources. [Explore](https://andrea-gentilini.github.io/explainable-italy/).
- [NeuralSegmentello](https://github.com/andrea-gentilini/NeuralSegmentello) — segmentation mask refinement, with a local demo and reproducible evaluation.
- [FART](https://github.com/andrea-gentilini/FART) — tokenization of audio representations for music generation.
- [KeyEar](https://github.com/andrea-gentilini/KeyEar) — keystroke recognition from audio.
